# ==============================================================================
# Deployment requirements - Hugging Face Docker Space (runtime only)
# ==============================================================================
# Installed by the Space Dockerfile. This is the SERVING set: everything the web
# app needs to answer questions. It deliberately omits the knowledge-base
# build/ingest toolchain, which is only needed when rebuilding the seed.
#
# Local development installs this PLUS requirements-build.txt:
#   pip install -r requirements.txt -r requirements-build.txt
#
# Verified against the import graph (2026-09-26): every package below is
# imported on a request path, at startup, or by a configured settings entry.
#
# OMITTED ON PURPOSE (requirements-build.txt has the full local set):
#   sentence-transformers, scikit-learn, fuzzywuzzy, python-levenshtein
#       Not imported anywhere in rag_app/. sentence-transformers alone pulls in
#       torch, by far the largest package in the original set.
#   pdf2image, Pillow, python-docx, tqdm, langchain-text-splitters
#       Only used by the build_knowledge_base management command.
#   pymupdf, opendataloader-pdf
#       Only used by the upload parsing path, disabled by default
#       (UPLOADS_ENABLED=False). opendataloader-pdf also requires a JRE.
#   llama-index-tools-tavily-research
#       Not imported; web search uses the tavily-python client directly.
#   llama-index-llms-openai-like
#       Removed 2026-10-06: it pulled transformers + torch (+294 MB RSS at
#       first import) only to POST JSON at OpenRouter. Chat now goes through
#       the in-repo OpenRouterLLM httpx client (query_agent_service.py).
#
# NOTE: django-htmx stays below even though no template uses hx-* attributes,
# because it is referenced by INSTALLED_APPS and MIDDLEWARE and Django imports
# it during startup. Removing it needs a settings.py change too.
#
# To re-enable document uploads on a deployment, add back pymupdf and
# opendataloader-pdf (opendataloader-pdf also needs a JRE runtime) and set
# UPLOADS_ENABLED=True.
